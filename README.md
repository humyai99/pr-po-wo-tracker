# pr-po-wo-tracker

หน้าเว็บ "STATUS ติดตามสถานะใบเบิก / PO / WO" — HTML/CSS/JS ไฟล์เดียว (`template.html`) ไม่มี library ภายนอก

- 1 แถวต่อใบเบิก (PR) ผูกกับ PO/WO, สถานะปัจจุบัน + ตัวแสดงขั้น, ผู้อนุมัติที่ถือเรื่อง, จำนวนวันที่ค้าง
- การ์ดสถานะ 7 แบบ (กดเพื่อกรอง), เลือกหน่วยงาน, ค้นหา, กรองเลยกำหนดใช้, เรียงคอลัมน์
- คลิกแถว → แผงสายอนุมัติ PR และ PO/WO
- โหมดมืด, พิมพ์ A4 แนวนอน, รองรับมือถือ

ข้อมูลฝังผ่านตัวแทน `/*__DATA__*/null` ในสคริปต์ (สคริปต์สร้างข้อมูลไม่ได้อยู่ใน repo นี้)
